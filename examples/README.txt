WhoBPyT Examples
================

Worked examples showing how to use WhoBPyT to build, fit, and analyse
whole-brain models of neuroimaging and neurophysiology data. Most examples
reproduce the main analyses of a published paper. Each one can be downloaded
as a Python script or a Jupyter notebook using the links at the bottom of the
example page.

Start with :ref:`ex-getting-started` for a quick demonstration of fitting
mechanics on a toy network. Continue with :ref:`ex-getting-started-connectome`
for real anatomical connectivity, alternative stimulation sites, and fitting
to synthetic evoked responses before moving on to empirical paper examples.
